# Events Sequence

Event Sequence Graphs with Feature Expressions

An Event Sequence Graph says which events may follow which: a vertex is an event, and an edge from one to another means that sequence is allowed. A test is a walk through the graph.

Pseudo events. [ and ] are not events the system performs. They mark where a run may begin and where it may end, so that every test is a path from [ to ] and the graph has one entry and one exit.

Feature expressions. The Fx is what makes one graph describe a whole product line. Every event carries a feature expression — soda, or a negation like ¬free. For a chosen configuration the events whose expression is false are dropped, and what is left is that product's own ESG. One model is drawn; a graph is derived for each product.

Coverage. Tests are generated to cover every event, or every ordered pair, triple or quadruple of consecutive events — the criterion chosen under the product configuration.

Kaya, Tuglular and Belli, “Software Product Line Testing based on Event Sequence Graphs with Feature Expressions,” UBMK 2023.
